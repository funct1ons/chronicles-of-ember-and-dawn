- 经济：先结算后征募、新收入延后、金币结转/上限、整数人数、活人口与死亡释放、零增长、达到income cap后的实际边际收益。

- UI：完整16兵图鉴、阵营/自定义设置、键盘选兵、暂停/恢复、变速、全屏、三音量与静音保存、战役锁定/解锁/下一章取消恢复结果、本地双人独立操作与赢家文案、教程/跳过、撤离确认、失败重开。

## 150单位与AI预算实测

`metrics/browser-performance.json`：高生命混合150士兵持续3秒的**纯负载夹具**（非合法平衡对局）：

- 120次绘图：中位 **0.5ms**、P95 **3.6ms**。
- 推进3秒模拟：总CPU约 **134.9ms**。
- 固定步 + RAF持续观察：457帧、约152次/秒、帧间隔P95约5.6ms，150单位仍存活。

另设正常生命、75+75民兵、每方80人口的独立AI检查，实际运行正式决策函数：

|难度|中位ms|最大ms|
|---|---:|---:|
|新手|0.0|2.1|
|简单|1.2|1.4|
|普通|16.9|31.5|
|困难|25.1|41.1|
|大师|0.3|0.5|

小军优势收尾预测最大31.7ms。所有难度及收尾均通过100ms门槛。大师均势大军不盲跑多候选预测，因此可以比普通/困难更快。冷启动、不同阵容/硬件仍可能有不同开销。

初轮发现184–240ms AI阻塞，原记录 `browser-performance-pre-budget-fix.json` 保留。随后限制预测场景/节点并使用整队互补评分，做了完整平衡与浏览器回归；没有以绘图FPS掩盖决策卡顿。

以上是本机headless观察，**不是显示器刷新率、所有设备60FPS或最坏情况上界保证**。当前采用有界O(n²)邻近判断、图帧缓存、粒子预算及音效并发；没有宣称已实现空间树或对象池。

## 音频实测及边界

`metrics/audio-runtime.json`：七状态均实际播放，媒体时钟从15秒继续前进、RMS非零、媒体解码错误null；静音后BGM和主总线归零。1000次混合音效触发刻意绕过同音色冷却，受管声部仍不超过20；采样sfxPeak约0.6192、最终outputPeak约0.6561，低于0.99门槛。测试不是所有可能合成叠加的数学上界证明。

五首原文件均已完整解码；整轨LUFS分析后运行时静态trim校准，`metrics/audio-loudness.json` 是分析结果，不是重新编码的交付音频。文件SHA256保持授权表记录。首尾包络/跨曲淡化不等于采样级无缝剪辑，Final Battle原曲保留一处停顿。

**未进行人耳主观试听。** 自动化只能证明解码、播放、电平与行为，不能证明音色、编曲、循环接缝或战争感染力达到主观标准。
