# 美术方向与资源规范

## Epic Dark Fantasy Pixel Art
非卡通的灰调像素战争：冷色深景、暖金界面、蓝金/赤铜旗帜、清晰金属高光。美术全部本项目原创，无原游戏贴图、Emoji士兵或拼贴素材。

## 制作方式
- `src/render/sprites.ts` 是**手工定义像素坐标的图集源文件**：48×48透明底，统一左上光照、深色轮廓、灰钢甲与阵营布料。不是把几何占位块当作成品。头盔/面甲、分节躯干、护腿、披风、武器、盾纹、弓弩/法杖/战马/弩炮逐层组合成完整像素轮廓。
- 16兵种按role拥有不同装备与形态；蓝红各一套统一色板。行走4帧腿部/身体起伏、攻击4帧武器/手臂动作、待机轻微变化，受击闪烁，死亡倾倒淡出。帧在首用时绘入缓存，无逐士兵实时重复画图。
- 世界基准为1280×540、场景640×270；v1.1按CSS视口与DPR建立backing（DPR上限2），48×48源精灵只以整数设备像素倍率复制，足点对齐设备像素。保留底部取景、必要时裁天空而不裁军队；完整要塞旗帜有可见性限制。HUD图鉴使用同一图集，不另用不一致插画。
- 30Hz模拟与RAF展示之间做位置插值，暂停冻结最后展示比例、重开清空历史。插值不是纹理平滑：`imageSmoothingEnabled=false`；像素对齐下慢速运动允许连续几帧保持一个物理像素，不承诺每帧必动。
- `src/render/scenery.ts` 提供四套原创环境：边境晨雾林地/暮色枯树荒原/雪山积雪与雪粒/古老柱廊与星火遗迹。三层山峦、远林、石材要塞、塔楼、门闸、风旗、火盆、地面纹理、篱笆、弃剑与前景草层统一像素密度。
- `BattleRenderer.ts` 负责脚底阴影、按y排序、箭矢弧线、魔法光点、金属火花、尘土、治疗、环境粒子与低血量要塞烟尘。粒子最多220；要塞冲击震屏为4Hz指数衰减、最多2物理像素；减少动态设置关闭震动和环境运动。

## UI
冷黑金属底、细金边框、蓝红军徽、宋体标题/雅黑信息字。无外部CDN字体依赖。首页是战地氛围而非调试面板；战斗中对称资源HUD、中央倒计时、兵种阵列和属性面板保持稳定位置。1024像素桌面窗口有专门布局；低于640像素不是首版目标。

### 首页封面：减少文案，而非堆叠装饰

首页专用 `src/ui/home.css`：居中四字宋体游戏名为唯一大标题，暖象牙白与克制鎏金配色；仅保留一行英文副题及一句「余烬未息 · 黎明将至」。移除右侧世界观小栏、重复页眉标题、说明型模式卡片和宣传文字；战役/经典两个主按钮，教学/试炼/自定义/双人一排文字入口，页脚只留鸣谢与战役进度。背景保留原像素战场，以轻量遮罩确保文字对比度，不新增字体或素材下载。

其它页面沿用原页眉；所有新样式限定首页，战斗画面/模拟/音频不变。专属浏览器用例检查640×480至1920×1080的六种窗口、键盘焦点与模式入口；验收结果及截图见测试报告。

v1.1图鉴提供折叠故事卡、搜索/定位筛选/价格排序、完整条目及战场B快捷键；搜索局部刷新列表，不重建输入框，保持键盘焦点。16条故事各60–110中文字符。9组虚拟DPR/窗口截图实际检查记录见 `metrics/v11-motion-browser.json`，不是实体Windows缩放或低配测试。

## 可维护与验收
像素图集为程序化原创资源源码（无需外部生成器），场景也随构建完整分发。`npm run assets` 可导出透明PNG精灵表与四地图PNG，供进一步人工美术替换与审阅。实际浏览器截图与压力画面见测试产物与 TEST_REPORT。当前像素动作不是逐帧手绘的复杂骨骼动画；这是本版美术制作方法，不宣称具有商业级手绘素材规模。
