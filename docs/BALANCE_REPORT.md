## 证据范围与复现

最终出生修复与AI保序扫描优化后的回归指纹：`30dddd5144bb093fb29cfa5a5f31a4504005866bcfde598bd8c1762b350477af`。当前源码521局全部重跑；六份报告的实际游戏结果与优化前逐项一致，`v11-regression-equivalence.json` 记录对比与模板seed元数据规范化原因（详见 `TEST_REPORT.md`），不是新增独立样本。逐文件 SHA256 与全部原始结果在 `metrics/`；`npm run metrics:report` 会拒绝核心/兵种/关卡源码不匹配的报告。指纹不是整个仓库的发布签名。

最终回归共 **521 局**：220 标准对战 + 60 策略对战 + 39 关卡 AI 烟测 + 128 关卡配方抽样 + 74 冻结后种子验证。它们是不同测试集合，**不是521个独立随机玩家样本**；重复运行相同种子不增加样本数。另有无盾试炼构造验证和3136个公共局面角色覆盖检查，单独计数。

- `balance-holdout.json`：种子301/509/997/1201/2027，双阵营；文件名holdout表示另一组种子，不应把反复观察后的结果称为严格盲测。
- `strategy-suite.json`：六类固定策略各10局，另13关卡每关3局AI烟测。
- `mission-playability.json`：407/811种子；每个普通关卡5类合法配方，无盾试炼额外增加斧兵/弓兵配方，限制关卡按允许兵种筛选。
- `fresh-validation.json`：8093/12547/19181种子最初在AI政策冻结后首次启用，双阵营74局。后来为等价距离优化及h1修订重复回归；不是每次执行都获得新的独立74局。
- v1.1 只对出生位置做了最小模拟修复：新兵选择同 lane 最近合法空位，避免出生重叠把已有士兵单步推开13px。兵种数值与AI评分未改；出生位置影响战局，所以全部重跑，不能沿用旧版胜率。
- 玩家配方在倒计时内选择兵种；内建AI按正式规则在双方收入入账后决策。没有向任何一方注入生命、伤害或金币。

## AI 可达性与性能

`ai-role-coverage.json` 在3136个人工构造、合法人口的公开局面中，16兵种全部至少被大师选择一次。治疗955次、弓手329次，弩车仅3次，斥候20次；这是**决策可达性检查，不是出场均衡或胜率证明**。

大师的均势大军采用整队互补评分；只有现存不超过28人且己方公开存活价值超过敌军3倍时启用有界34秒收尾预测，含增援最多64节点。普通/困难使用较短的候选预测。测试验证：不读取未公开的敌方下一波选兵，不修改真实状态/RNG，遵守growth=0、收入上限、兵种限制及人口。

v1.1首轮完整E2E的正常生命75+75民兵测试中，困难AI出现一次144.8ms，超过100ms门槛（`v11-browser-performance-first-failure.json`）。原样三次复测均通过，困难峰值81.7 / 93.1 / 46.8ms（`v11-ai-repeat-probe.json`）；不能据此抹去初次失败或确定尖峰原因。已完成不改评分与预测规则的保序扫描优化，167快照/13,496预测字段/1,990次AI选择与完整状态精确一致。主侧优化后3次独立浏览器困难峰值50.3 / 44.6 / 60.2ms；最终整套12项E2E全通过，最新离线缓存修复后的整套回归中，困难峰值43.7ms、普通64.3ms、大师1.5ms、小军收尾79.8ms（此前完整回归困难39.2ms）。100ms门槛不放宽；原尖峰原因仍未确证，实测不等于任意设备/阵容的最坏上界。没有用高生命绘图夹具代替合法战局AI测量。

## 无盾试炼可解性修复

旧配置双轻甲射手镜像出现长时间僵持，失败记录保留于 `metrics/challenge-witness-before.json`。最终h1采用明示非对称兵种谜题：双方同金币/收入、人口65；敌方民兵/斥候/弓/弩/刺客，玩家额外允许无盾重甲战斧。没有改全局兵种属性或AI权重。

`challenges:witness` 在101种子蓝方27种合法配方中选取最快胜局：民兵先到320收入，再逐波战斧/弓手轮换。用101/203/307双阵营验证，6局均自然摧毁敌方要塞，模拟272 / 318 / 158 / 296 / 370 / 249秒。另困难AI镜像6局为5胜1平，其中5局攻破基地、1局966秒平局。

这是**构造性可解证据**，不是人类通关率；搜索与验证有一局重复，不能冒称六局全是未见种子。正式抽样h1为2胜4平6负，也不能拿挑出的最优配方6/6覆盖失败结果。

## 调优与后续边界

开发中修复了growth=0回退、基地索敌被远处敌兵阻断、前排挤压导致近战无法出手等问题；大师由局部单兵评分改为整波互补/实际收益与有限收尾预测。另一次纯距离平方优化前后519个旧配置结果逐项一致（CPU时间除外），记录 `distance-optimization-check.json`；该历史证据早于h1改版，不是当前额外519局独立验证。

首版已排除这些测试内明显的纯单兵必胜与经济无限循环问题，但未证明全策略平衡。下一轮应优先做：人类完整战役试玩、普通/困难长局改善、经济转精英反制、c5难度过渡、攻城单位使用率与多设备预算。未为漂亮胜率临时给大师隐藏加钱，也未把重复回归当成新增统计证据。
