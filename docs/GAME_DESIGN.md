# 烬辉战纪 · 设计与模块契约

## 定位
离线、静态部署、Windows PC 浏览器的原创自动战争策略游戏。受经典 Miragine War 启发，不复制原游戏资源和未证实的原版数值。两个阵营是视觉身份，使用相同兵种数值保证公平。

星火之心破裂，埃瑟兰陷入苍曜同盟与赤烬军团之战。玩家是军团统帅，以每波兵种选择经营收入、守住己方要塞并摧毁敌方。叙事不阻挡对战。

## 原创规则
- 1280×540 逻辑战场，八条软队列构成横向兵团战场，单位自动行军、攻击与寻敌。
- 模拟固定 30Hz，渲染 requestAnimationFrame与位置插值，暂停冻结最后展示位置，页面失焦自动暂停。最多累计 0.2 秒，避免恢复页面后跳过战局。
- 首波准备 6 秒，之后默认每 12 秒结算一次。先把已有收入加入金币，再按选中兵种批量购买，最多 18 人/波，受金币和剩余人口约束；费用扣除后增加后续收入。收入上限 600，金币上限 6000。
- 默认金币 150、收入 80、人口 80、要塞生命 2500。金币和收入都是双方相同规则；高难度只改善决策，不添加隐性资源。战役显式非对称条件例外，关卡中说明。
- v1.1新兵在同lane选择最近合法出生空位，避免新波出生重叠把已有单位推开；不新增随机消耗。
- 活着的单位占人口，死亡释放；不在波次重置全部人口。轻/重甲使用两套伤害，并扣减固定护甲值（最低伤害2）。魔法无视护甲值。
- 反骑枪兵、重盾减伤、骑兵首击、范围火法、祭司治疗、攻城倍率、刺客反后排等提供组合策略。所有单位配置在 `src/data/units.ts`。
- 双方要塞同时毁灭为平局；最多80波征募，最后一波获得一个完整作战窗口，之后按要塞剩余生命判定（相同为平局），防止无限僵持。

## 技术选择
TypeScript + Vite + Canvas 2D + DOM/CSS + Web Audio。无需 Phaser 的场景/物理系统，减少依赖与运行体积。核心不引用 DOM、音频或渲染，可在 Vitest/Node 自动模拟。

模块：`src/core`纯模拟/AI/类型，`src/data`兵种/关卡，`src/render`像素图集/环境/特效，`src/audio`本地音乐和音效，`src/ui`页面/持久化，`src/main.ts`驱动与整合。场景像素化逻辑尺寸640×270；v1.1按CSS尺寸与DPR建立backing（DPR上限2）。角色图帧48×48、主要人形轮廓约16×34像素，整数设备像素倍率复制，保持一致光照和描边。战斗视窗等比缩放并从底部取景，不横纵分别拉伸角色；窄高窗口与宽屏可见的上方天空范围不同。

## AI 与公平性
- 五档难度共用同一经济、人口、伤害与征募规则。没有隐藏金币、伤害倍率或在线服务。
- 新手/简单分析有效战力与经济，但有较高选择噪声；普通使用前三候选的16秒粗略预测，困难使用前六候选22秒预测。大师首先评估所有可负担兵种加入后的整支军队：前排、远程火力、治疗按互补与边际递减计分，再考虑实际增收的再投资窗口；不把一个短预测的幸存单位价格当作经济真理。大师只在现存单位不超过28、己方公开存活价值超过敌军3倍的收尾局面做34秒粗预测，连同双方最多36个增援节点仍不超过64。均势大军走低复杂度组合评分，避免150兵时每波阻塞约200ms。
- `combat.ts` 是战斗与AI共用的有效伤害计算；`tactics.ts` 按整波成本/人口/实际裁剪增收、当前残血、射程、前排、治疗、溅射与移动时间评估加入该波后的阵线，而非只给单兵分数。
- 战术预测是有界、同步伤害的低精度近似，**不是另一套权威物理引擎，也不是搜索未来真实随机数**。它读取已公开的资源与已出现军队，按最近出现的兵种预测敌方续兵；不读取对手当前尚未公开的下一波选项。测试验证选择不因该选项变化而改变。
- 高档AI在近满人口且前排过量、火力不足时会保留空人口等待关键远程单位，而不是永远用盾兵填缝。
- 难度曲线、全兵种可达性与固定策略对局以实际指标为准，见 BALANCE_REPORT；有限样本不证明万能最优。

## 模式与交互
经典对战、10关战役、3个挑战、自定义、本地双人。自定义支持四地图、5档AI、金币、人口、收入增长和速度。战役按胜利解锁关卡，胜负统计和设置存在 localStorage；不存正在进行的战局。

挑战I「最后的箭袋」是明示非对称兵种谜题：敌方只有民兵、斥候、弓手、弩手与刺客；玩家额外拥有无盾的重甲战斧。双方资源与人口65完全相同。战斧承受箭雨、弓手反制穿甲弩，避免原先双轻甲射手阵容的长时间镜像僵持。构造性验证中，先建立320收入，再轮流征募战斧/弓手，在3种子双阵营6局均攻破要塞；这不是玩家群体胜率估计。

单人16键：1–8、Q/W/E/R/T/Y/U/I；双人左方1–8与Q–I，右方可用下方独立鼠标兵种栏或按方向键浏览、Enter确认。空格暂停，+/-速度，M静音，B完整兵种条目（U仍选火法），F全屏，Esc暂停/关闭面板。所有关键操作也有按钮。

## v1.1文案与声音

16兵种各60–110字原创军志故事；图鉴支持定位筛选、搜索/排序、折叠完整属性和按真实伤害推导的适性提示。效率与理论回本明确前提，不冒称实战胜率。

战斗/高潮使用同一Final主曲，不重置播放头；高潮叠加按素材瞬态提示调度的稀疏打击层。真实时间45秒最短强度变化间隔、3/6秒进入/退出滞回；1.6秒双甲板循环交叠，不重新编码原音乐。详见 AUDIO_DIRECTION。

## 验收原则
测试核心与浏览器交互；实际截图验收不是以静态代码替代。实测结果见 TEST_REPORT 与 BALANCE_REPORT。性能、音频主观质量及未完成项如实列出，不宣称跨设备普适保证。
