# 兵种外观辨识度审查

## 结论与范围

确实存在明显的同兵种家族辨识问题，尤其是民兵/盾卫/精英步兵、三种施法者、斥候/刺客。两军蓝红阵营易分，不等于同一阵营的不同战术角色易分。

本轮只分析；没有修改 `src/`、`public/`、兵种数值、动画或玩法，没有提交或部署。此前缓存诊断的未提交文件保持不动。

## 依据

- 实际阅读 `src/render/sprites.ts`、`BattleRenderer.ts`、`pixelViewport.ts` 与16兵种设定。
- 实际查看原图集、图鉴肖像和150单位负载截图；负载截图仅观察拥挤时的视觉可读性，不作为正常对战阵容/平衡证据。
- 从本地运行中的精灵函数直接生成16兵种、双阵营、原像素整数2倍对照图：`screenshots/unit-appearance-audit.png`。这是诊断拼图，不是新美术，也不是战场实际显示大小。
- 同原点、48×48帧、alpha≥128的轮廓掩码交并比，记录于 `metrics/unit-appearance-audit.json`。**这是特定帧的像素几何指标，不是人类误认率、画质总评分或所有相似感的充分条件。** 主要针对共同骨架是否导致轮廓重复。

## 主要混淆组

| 分组 | 实际观察 | 优先级 |
| --- | --- | --- |
| 誓约民兵 / 铁壁卫士 | 同盔、同剑、同尺寸纹章盾；差别主要是躯干与护胫材质；idle轮廓交并比约99.1% | 最高 |
| 星辉术士 / 曙光祭司 / 烬火贤者 | 同长袍外形、同兜帽、同直杖/菱形杖头；主要更换帽内与杖头颜色；三对idle轮廓一致，抽查walk/attack四帧仍一致 | 最高 |
| 逐风斥候 / 夜幕行者 | 同兜帽、体型、披风与主手剑；刺客加一把很短的副手刃；idle轮廓交并比约96.8% | 高 |
| 铁壁卫士 / 破晓执誓者 | 精英主要多了小盔饰与金线；idle轮廓交并比约95.5%，共同不透明区域的原RGBA相同像素占并集约91.5% | 高 |
| 曜石禁卫 / 其他盾剑步兵 | 禁卫加宽躯干、加高盾牌，确有区别，但仍属于同一套盾剑骑士轮廓；黑甲身份表达不足 | 高 |
| 风暴轻骑 / 苍穹重骑 | 骑乘轮廓共享；重骑有盾、盔饰和局部马铠，近看可分，混战中更难；idle轮廓交并比约94.8% | 中 |
| 长枪 / 战斧 / 弓手 / 弩炮 | 长武器、弓弧、车体已有较强外轮廓；弩手的小弩仍可强化，但不是首要问题 | 较低 |

## 根因

1. **模板统一超过了角色个性。** 除器械外，大量角色共享头、躯干、披风、腿部及手臂坐标；不同role大多只是选配装备。仅按role分支不等于最终画面具备16种可读轮廓。
2. **关键区别放在内部小像素。** 盔饰、兜帽内衬、宝石色和护胫的几像素变化，远不如武器长度、盾型、头型、体态有效。
3. **阵营色占据过多职业差异预算。** 三种施法者的袍身实际都使用同一阵营cloth色；`UnitDef.color`也不是每个role都会使用，数据里的16种颜色不代表精灵有16套职业配色。
4. **动作语言仍同质。** 共享步频、步幅和四帧挥击骨架；武器与弓弦/器械有局部专用动作，但治疗、奥术、火术的姿态区别仍不足，不能依靠动起来自动解决。
5. **战场会放大问题。** 同阵营拥挤、遮挡下，盾牌和衣褶先被遮住，常只剩头盔与武器尖端。48×48是源帧规格，不是每个分辨率下的CSS尺寸；整数倍率保清晰不等于增强职业信息。
6. **部分视觉与设定不一致。** 民兵设定为廉价短矛木盾，实际是金边纹章盾与金属剑盔；禁卫的黑甲设定、祭司的治疗身份也没有足够鲜明的外形支撑。

## 建议方向（尚未实施）

先重构最容易混淆的家族，而不是给所有人再加金边、光晕或颜色：

- 民兵：简陋头具、布/皮甲、小圆木盾或朴素短武器；盾卫：真正主导轮廓的大盾与沉稳重心；禁卫：更宽厚黑甲与独特全盔；执誓者：独特冠盔、剑型与披风。装备最终方案需要保持设定一致，不把视觉暗示误作新增能力。
- 奥术：独特星形/环形法器与收束姿态；祭司：白金祭服、不同头具与祝祷手势；火术：明显不同的杖头、破边袍形和施法姿态。光效只作第二识别线索。
- 斥候：轻装短披肩、前倾奔跑；刺客：更低重心、非对称斗篷、双刃与不同攻击节奏。
- 轻骑：轻马具、短披与灵活姿态；重骑：完整马铠、显著不同的头盔/骑枪或大盾轮廓。武器选型仅是美术建议，不改变射程和技能。

验收应以**同阵营、无名称、实际战场尺寸**为主，同时看静止/行走/攻击、灰度/剪影与遮挡混战。测试人是否认得出兵种及战术类别；像素IoU仅作辅助，不把阈值当作人类识别通过线。维持统一像素密度、阵营辨识和亮度，不用花哨特效掩盖重复轮廓。
