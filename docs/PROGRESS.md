## 重要决策

- TypeScript + Canvas2D + DOM/CSS + Web Audio，避免为了框架而增加运行依赖；模拟与渲染/音频/UI分离。
- 不复制原版未经核实常数；首6秒后12秒、先收入后征募、活单位持续占人口均明示为本作规则。
- 阵营数值一致，经典高难度不隐藏加钱；战役非对称条件显示在简报。
- 大师采用整队互补/边际收益评分，小军优势收尾才有界预测；不窥对手尚未公开的选兵。
- 像素图帧/合成音效为本作原创，成品交响乐使用CC0原文件；不把生成方式或素材规模包装成商业手绘/真人录音库。
