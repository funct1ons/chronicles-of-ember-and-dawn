# v1.1 方案与实施追踪：图鉴 / BGM 连续性 / 士兵抖动

用户已批准：**16条各60–110字故事；乙（连续主曲 + 高潮协调叠层）；J1–J4证据驱动运动优化与全量回归**。

## 一、已确认的原始问题

### 图鉴

旧版已有16种兵的完整属性，但没有故事、检索/筛选/排序，战场暂停速览只有简版。不是从零添加属性，而是完善查阅体验。

### 音频

- 战斗/高潮原用不同歌曲，按模拟时间短间隔切换，并把播放头归零，反复只播放开头。
- 旧首0.6秒/尾1.1秒 `seam` 包络会把媒体增益降到0；素材自身也可能有淡尾，二者不能混为一谈。
- 首次存档音乐默认0.45，经过trim/场景系数后偏低；既有整轨LUFS trim不必重做。
- `new Audio()` 不挂DOM，`querySelectorAll('audio')` 查不到不能证明音频没播放。
- 稳态20秒采样没有发现额外音量跌落；ducking不能被无证据认定为主因。

**旧诊断中的错误推断已纠正**：包络有低音量不等于整段“完全静音”；素材静音长度依测量阈值而异。旧 `.tmp` 文件不作为最终验收证据。

### 运动

- 30Hz模拟坐标直接用于高刷新RAF，无插值；旧半世界坐标取整、固定backing与非整数精灵缩放会放大量化台阶。
- 旧震屏约10Hz，需低频、低幅并支持减少动态效果。
- 旧逐帧工具只取前四个walking单位，再跨缺失数秒直接相减，所谓45px/535px“单帧瞬移”无证据效力。
- `yieldX` 只是目标，原代码已有 `speed * dt` 限速；禁止盲目为它补“瞬移修复”。

## 二、图鉴方案与落地

1. 每兵种新增 `lore` 与 `doctrine`，16条原创军志故事，60–110中文字符；两军同兵种不同军事气质，不编复杂RPG人物网。
2. 名称/定位/故事搜索，步兵/远程/骑兵/法术/攻城/精英筛选，价格升降序；不重新渲染搜索控件导致焦点丢失。
3. 默认折叠显示故事预览；展开完整故事、属性、特殊能力、效率与真实伤害适性。
4. 提示由实际 `computeDamage()` 推导，轻甲低防不误标“惧穿甲”；不把单击伤害或理论TTK冒称实战胜率。
5. 效率明示前提：收入/金币、生命/金币、生命/人口、整数波理论回本（增长1、未封顶、不计复投）。
6. 战场快捷键 **B** 打开当前检视单位完整条目；**U保留原选火法功能**；暂停速览也进入相同完整详情。

图鉴仅加文案字段，16/16兵种去掉新字段后与v1.0属性完全一致。覆盖纯函数单测、内容断言及真实浏览器搜索/筛选/焦点/详情暂停与恢复测试。

## 三、已选择的音频乙方案

1. `battle` 与 `climax` 共用 Final 录音、同播放甲板、同播放头；高潮只平滑提升约2dB与增加非旋律低鼓/军鼓层。
2. 不是凭空指定BPM：按部署录音的低频瞬态提取32个稀疏重音提示点，跟随媒体时钟，循环/卡顿重新同步而不补播积压。
3. 真实时间滞回：≥24接敌或要塞危急持续3秒进入；≤12且安全持续6秒退出；变化间隔≥45秒。
4. 去掉首尾归零包络，以懒创建的第二流式甲板进行1.6秒恒功率交叠、约提前20秒准备。**未采用离线重新编码方案**，原音乐文件及授权SHA保持不变。
5. 默认音乐0.80；已有存档不强制覆盖。叠层跟随音乐滑块、静音和销毁，不走音效音量。
6. 备战用March，胜利用Hope，胜负从开头起奏，避免原先胜利只延续备战曲中段。

验收：音频纯函数单测、真实浏览器循环/切换/滑块/销毁测试；305秒真实PCM长测已通过，3812样本，无检测到静音/停播，两次自然循环，5次强度切换均不重置播放头。**仍未完成人耳听审**。详见 `AUDIO_DIRECTION.md`、`TEST_REPORT.md`。

## 四、J1–J4运动方案

- **J1 插值**：每个固定step前捕获位置；RAF按accumulator插值。暂停冻结最后展示比例，快进显示最新位置，重开清空历史，不改变模拟坐标。
- **J2 像素对齐**：DPR backing上限2；人物源像素整数倍率，足点对齐设备像素；维持底部取景、裁天空而非军队，防右城堡旗帜被裁。
- **J3 震屏**：4Hz指数衰减，最大2物理像素；reducedMotion禁用。
- **J4 仅修实证异常**：全tick审计复现seed19181/tick3151，新波出生重叠触发纠正，将已有弩炮单步推开13world px。只将出生点改为同lane最近合法空位，不增RNG，不改移动/碰撞/AI/兵种数值。

修后全tick审计44,769 tick / 1,941,038相邻单位样本，最大2.744px，无>6px。9组1024/1440/1920 × DPR1/1.25/1.5真实RAF检查另行记录；虚拟DPR不冒充实体Windows缩放/低配测试。
